# Reference Papers Repository

This directory stores past CUMCM excellent papers and LaTeX source codes.

## Download Sources

1. CNKI: Search math modeling + excellent papers, filter for provincial first prize+
2. GitHub: Search CUMCM+year+paper
3. University Websites: Math modeling associations often publish excellent papers

## What to Learn from Samples

1. Abstract Structure: 5-paragraph format
2. Equation Numbering: Important equations must be numbered
3. Figure/Table Specs: Figure title above, table title above
4. References: At least 10, mix of Chinese and English
5. Code Appendix: Core algorithms in appendix
