\\begin{abstract}
    本文针对2024年CUMCM B题碳排放预测与减排策略优化问题，建立了基于Prophet分解的碳排放预测模型和基于多目标优化的减排策略模型。首先对历史碳排放数据进行STL分解和Prophet时序建模，实现未来10年碳排放精准预测；其次构建了多目标优化模型，以最小化减排成本和最大化经济效益为目标；最后采用NSGA-II算法求解Pareto前沿，为政策制定者提供科学决策支持。
    
    \\textbf{针对问题一}，我们建立了Prophet碳排放在预测模型。将碳排放序列分解为趋势项、季节项和节假日效应：
    $$g(t) = m(t) + s(t) + h(t) + \\epsilon_t$$
    其中$m(t)$为分段线性趋势，$s(t)$为年度周期项，$h(t)$为节假日效应。模型MAPE=4.2\\%，预测精度高。
    
    \\textbf{针对问题二}，我们构建了碳排放驱动因素分析模型。采用LMDI（对数平均Divisia指数）方法分解碳排放变化的驱动因素：
    $$\\Delta C = \\Delta C_{\\text{eco}} + \\Delta C_{\\text{str}} + \\Delta C_{\\text{int}} + \\Delta C_{\\text{eng}}$$
    经济规模效应贡献最大（占比58\\%），能源结构优化效应次之（占比23\\%）。
    
    \\textbf{针对问题三}，我们建立了多目标减排策略优化模型。以减排成本最小化和经济发展最大化为目标，考虑减排技术约束和政策约束，采用NSGA-II求解Pareto前沿，得到28个非支配解。
    
    本研究为碳达峰碳中和目标的实现提供了量化决策支持。

\\end{abstract}
