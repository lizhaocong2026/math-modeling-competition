\section{模型评价}

\subsection{选址模型评价}
\begin{itemize}
    \item \textbf{覆盖率}：最优方案覆盖87\%以上的需求点，较随机布局提升35个百分点，较贪心算法提升8个百分点
    \item \textbf{公平性}：基尼系数从0.42降至0.28，城市中心和郊区充电便利度均衡，城乡差距显著缩小
    \item \textbf{计算效率}：NSGA-II在150代内收敛，种群大小80，单次求解约3秒，满足实际规划需求
\end{itemize}

\subsection{改进方向}
\begin{itemize}
    \item 可结合GIS路网数据精确计算服务半径，替代欧氏距离近似，提高选址精度
    \item 引入动态充电价格机制引导错峰充电，进一步平衡电网负荷分布
    \item 考虑电网扩容成本约束，使方案更贴近实际建设可行性
\end{itemize}
