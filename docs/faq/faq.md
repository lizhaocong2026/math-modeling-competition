## 一、选题决策

**Q: A/B/C题分别适合什么背景的学生？**
- A题（优化调度）：理工科，有编程基础，适合喜欢算法挑战的同学
- B题（预测趋势）：数据敏感，有统计基础，适合细心和分析型同学
- C题（评价决策）：文科/商科也可，侧重逻辑推理和数据分析

**Q: 三人团队如何分工？**
- 编程手：负责算法实现、调试、结果输出
- 建模手：负责问题转化、模型构建、公式推导
- 写作手：负责论文撰写、图表制作、格式排版

---

## 二、算法选择

**Q: 多个算法结果不一致怎么办？**
- 以结果最稳定的算法为主
- 做灵敏度分析验证稳健性
- 在论文中对比多种方法，体现思考深度

**Q: 什么时候用启发式算法而不是精确算法？**
- 问题规模大（变量>50）且NP-hard
- 对最优性要求不高，求满意解即可
- 时间受限（竞赛3天内）

---

## 三、数据处理

**Q: 数据缺失太多怎么处理？**
- 缺失 < 5%：均值/中位数填充
- 缺失 5%-20%：多重插补或KNN填充
- 缺失 > 20%：考虑删除该变量或寻找替代数据源

**Q: 数据量太少（<10个）怎么预测？**
- 使用 GM(1,1) 灰色预测
- 结合机理模型（物理规律）
- 敏感性分析替代验证

## 四、论文写作

**Q: 摘要写多少字合适？**
- 800-1000字为宜
- 第一段：问题重述+建模思路
- 第二段：模型1（假设+推导+求解）
- 第三段：模型2（如有）
- 第四段：结果+灵敏度分析

**Q: 图表有什么规范要求？**
- 所有图表必须有编号和标题
- 坐标轴要有单位和刻度
- 配色避免红绿（色盲友好）
- 推荐 SciencePlots 风格

---

## 五、代码问题

**Q: 算法跑不出来或报错怎么办？**
1. 检查输入数据维度是否正确
2. 打印中间变量确认每一步
3. 用小数据集先验证逻辑
4. 查看 algorithms/ 下的 docstring

**Q: 如何提高算法运行速度？**
- 向量化计算（避免Python for循环）
- 使用 numpy/scipy 而非纯Python实现
- 适当减小 pop_size 或 max_gen
- 并行计算（multiprocessing）
