## 二、A题优化类分支

`
A题优化
  │
  ├─ 单目标 → 线性/整数规划 → 国家数据/行业报告
  │           → GA/PSO/SA → 任意结构化数据
  │
  ├─ 多目标 → NSGA-II → Pareto前沿分析
  │           → 需多组数据源
  │
  ├─ 路径问题 → ACO/TSP → GIS数据/高德地图
  │
  ├─ 选址问题 → 混合整数规划 → CADMAPPER/遥感
  │
  └─ 组合优化 → 动态规划/枚举 → 离散数据
`

## 三、B题预测类分支

`
B题预测
  │
  ├─ 数据量<10 → GM(1,1)灰色预测 → 统计年鉴
  ├─ 数据量10-100 → ARIMA/Prophet → 金融/气象数据
  ├─ 数据量>100 → LSTM/GRU → 股票/流量数据
  ├─ 有季节性 → Prophet → 电商/互联网数据
  └─ 多因素 → 回归/随机森林 → 多维度数据
`

## 四、C题评价类分支

`
C题评价
  │
  ├─ 有专家知识 → AHP主观赋权 → 行业报告
  ├─ 数据充分 → 熵权法客观赋权 → 任何数值数据
  ├─ 主客观结合 → 组合赋权 → 混合数据源
  ├─ 高维数据 → PCA降维 → 多维数据集
  └─ 排序选择 → TOPSIS/VIKOR → 政府公开数据
`

## 五、跨学科融合场景

| 场景 | 算法组合 | 数据源 |
|------|---------|--------|
| 新能源选址 | AHP+TOPSIS+GA | 遥感+GIS+行业报告 |
| 碳排放优化 | ARIMA+LP | 国家数据+FAO |
| 空气质量评价 | PCA+熵权+TOPSIS | PM25.in+气象 |
| 股票情绪分析 | LDA+SVM+LSTM | 百度指数+金融 |
