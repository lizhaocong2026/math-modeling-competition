# 常见错误与避坑指南

> **对应笔记**：[[竞赛指南-CUMCM全流程]] · [[算法实现详解-代码速查]]

---

## 一、建模阶段常见错误

| 错误 | 表现 | 避免方法 |
|------|------|---------|
| 假设过多 | 假设占论文1/3篇幅 | 只保留必要假设，每项说明理由 |
| 模型过复杂 | 用深度学习解决小样本问题 | 数据量<100用传统方法 |
| 变量未定义 | 公式中出现未解释符号 | 所有符号在首次出现时定义 |
| 约束遗漏 | 忽略隐含约束条件 | 列出所有约束并编号 |
| 单位不统一 | 混用不同单位制 | 统一到SI单位制 |

## 二、算法实现常见错误

| 错误 | 表现 | 避免方法 |
|------|------|---------|
| 维度不匹配 | ValueError: shape mismatch | 打印各数组shape检查 |
| 收敛陷阱 | 迭代无改善 | 增加max_gen或换算法 |
| 局部最优 | GA早熟收敛 | 增大种群或加入精英保留 |
| 除零错误 | division by zero | 加epsilon保护 |
| 梯度消失 | LSTM训练慢 | 用GRU或加batch norm |

## 三、论文写作常见错误

| 错误 | 表现 | 避免方法 |
|------|------|---------|
| 摘要空洞 | 只有结论没有过程 | 摘要包含：方法+结果+验证 |
| 图表无编号 | 图1出现在文字之前 | 先编后引，按出现顺序编号 |
| 公式不居中 | LaTeX公式左对齐 | 使用align环境 |
| 参考文献乱 | 引用格式不统一 | 用Zotero管理参考文献 |
| 语言口语化 | 我们觉得 | 改为实验表明 |

## 四、数据处理常见错误

| 错误 | 表现 | 避免方法 |
|------|------|---------|
| 数据泄露 | 测试集信息进入训练 | 严格划分train/test |
| 量纲不一致 | 不同量级特征主导 | 标准化/归一化 |
| 异常值未处理 | 少数极端值扭曲结果 | IQR或3sigma检测 |
| 时间序列未打乱 | 未来信息泄露到过去 | 保持时间顺序 |
