# 论文写作规范

## 一、论文结构

### 标准格式
```
标题（居中，黑体三号）
作者姓名（居中）
摘要（500字以内）
关键词（3-5个）

一、问题的重述
二、问题的分析
三、模型的假设
四、符号说明
五、模型的建立与求解
    5.1 模型一的建立与求解
    5.2 模型二的建立与求解
六、模型的评价与推广
七、参考文献
八、附录
```

---

## 二、摘要写作

### 要求
- 独立成文，不看正文也能理解
- 包含：问题、方法、结果、结论
- 字数：300-500字
- 语言精炼，避免冗长

### 模板
```
本文针对XXX问题，建立了XXX模型。首先，
通过XXX方法对数据进行了处理；其次，
采用XXX模型进行求解；最后，通过XXX
方法对结果进行了验证。结果表明：
XXX。该模型具有XXX优点，可用于XXX。
```

---

## 三、模型建立

### 写作要点
1. **先画图**：流程图、思维导图
2. **先假设**：列出所有假设
3. **先符号**：统一符号表
4. **先公式**：写出核心公式
5. **后解释**：解释公式含义

### 公式编号
```
(1+2x)/(1+x²) = y    (1)
```

### 定理引用
> **定理1**（KKT条件）...
> 证明：由拉格朗日函数...

---

## 四、结果分析

### 写作框架
1. 展示结果（表格/图形）
2. 描述现象（数据特征）
3. 解释原因（理论分析）
4. 对比验证（与其他方法）
5. 灵敏度分析（参数影响）

### 图表规范
- 图题在图下方
- 表题在表上方
- 图表要自明
- 字号适中（9-11pt）

---

## 五、常见问题

### 1. 模型过于复杂
- 简化模型，抓住主要矛盾
- 用简单的模型解释清楚问题

### 2. 结果不合理
- 检查计算过程
- 进行灵敏度分析
- 与现实数据对比

### 3. 论文结构混乱
- 按模板组织内容
- 目录清晰，层次分明
- 摘要写最后
