# 附录：常见问题解答

## 一、算法选择

**Q: 如何选择优化算法？**
- 小规模、连续、光滑 → 梯度下降、Newton法
- 大规模、连续 → PSO、DE
- 离散、组合 → GA、ACO
- 多峰、易陷局部 → SA
- 多目标 → NSGA-II、MOEA/D

**Q: 预测模型怎么选？**
- 数据少(<20) → GM(1,1)
- 数据多、有趋势 → 回归
- 数据多、有季节 → ARIMA
- 需要精度 → 集成方法

## 二、数据处理

**Q: 缺失值怎么处理？**
- 缺失<5%: 删除
- 缺失5-30%: 填充（均值/中位数/插值）
- 缺失>30%: 考虑删除或用模型预测

**Q: 异常值怎么处理？**
- 先检查是否是数据错误
- 如果是真实值，用箱线图法则或IQR处理
- 敏感性分析验证结果稳定性

## 三、论文写作

**Q: 摘要怎么写？**
- 最后写，先完成正文
- 包含：问题、方法、结果、结论
- 避免空洞描述，要有具体内容

**Q: 图表怎么处理？**
- 每个图表都要有标题
- 图表要自明（不看正文也能理解）
- 分辨率≥300dpi

## 四、竞赛技巧

**Q: 三天时间安排？**
- 第1天: 审题(1h) → 建模(3h) → 编程(10h)
- 第2天: 完善模型(6h) → 灵敏度分析(4h) → 结果验证(4h)
- 第3天: 论文撰写(10h) → 修改检查(4h) → 提交(2h)

**Q: 遇到瓶颈怎么办？**
- 换思路，不要死磕
- 简化模型，先出结果
- 分工合作，并行处理
