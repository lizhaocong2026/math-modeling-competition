# 算法原理详解

## 一、线性规划单纯形法

### 1. 算法思想
从可行域的一个顶点出发，沿边界移动到相邻顶点，使目标函数值不断改善，直到找到最优解。

### 2. 计算步骤
```
步骤1: 化为标准型
步骤2: 找初始基可行解
步骤3: 检验最优性 (所有检验数≤0)
步骤4: 确定入基变量 (最大正检验数)
步骤5: 确定出基变量 (最小比值规则)
步骤6: 换基迭代
步骤7: 重复步骤3-6直到最优
```

### 3. 示例
```
max z = 3x₁ + 2x₂
s.t.  x₁ + x₂ ≤ 4
      x₁ - x₂ ≤ 2
      x₁, x₂ ≥ 0
```

加入松弛变量s₁, s₂:
```
max z = 3x₁ + 2x₂ + 0s₁ + 0s₂
s.t.  x₁ + x₂ + s₁ = 4
      x₁ - x₂ + s₂ = 2
```

初始单纯形表:
| 基 | x₁ | x₂ | s₁ | s₂ | RHS |
|----|----|----|----|----|-----|
| s₁ | 1 | 1 | 1 | 0 | 4 |
| s₂ | 1 | -1 | 0 | 1 | 2 |
| z | -3 | -2 | 0 | 0 | 0 |

## 二、灰色预测GM(1,1)推导

### 1. 数据预处理
原始序列: x⁽⁰⁾ = (x⁽⁰⁾(1), x⁽⁰⁾(2), ..., x⁽⁰⁾(n))

累加生成: x⁽¹⁾(k) = Σᵢ₌₁ᵏ x⁽⁰⁾(i)

### 2. 白化方程
dx⁽¹⁾/dt + ax⁽¹⁾ = b

### 3. 离散形式
x⁽⁰⁾(k) + a·z⁽¹⁾(k) = b
其中 z⁽¹⁾(k) = 0.5(x⁽¹⁾(k) + x⁽¹⁾(k-1))

### 4. 参数估计
令 Y = [x⁽⁰⁾(2), ..., x⁽⁰⁾(n)]^T
B = [[-z⁽¹⁾(2), 1], [-z⁽¹⁾(3), 1], ..., [-z⁽¹⁾(n), 1]]

â = (a, b)^T = (B^TB)⁻¹B^TY

### 5. 时间响应函数
x̂⁽¹⁾(k) = (x⁽⁰⁾(1) - b/a)e^{-a(k-1)} + b/a

### 6. 还原值
x̂⁽⁰⁾(k) = x̂⁽¹⁾(k) - x̂⁽¹⁾(k-1)

## 三、TOPSIS法矩阵推导

### 1. 原始矩阵
X = [x_ij]_{m×n}

### 2. 归一化
z_ij = x_ij / √(Σᵢ x_ij²)

### 3. 加权矩阵
v_ij = w_j · z_ij

### 4. 理想解
v⁺ = (max v_1j, max v_2j, ..., max v_mj)
v⁻ = (min v_1j, min v_2j, ..., min v_mj)

### 5. 距离计算
D_i⁺ = √(Σⱼ(v_ij - v_j⁺)²)
D_i⁻ = √(Σⱼ(v_ij - v_j⁻)²)

### 6. 贴近度
C_i = D_i⁻ / (D_i⁺ + D_i⁻)

## 四、KMeans聚类算法

### 1. 算法步骤
```
输入: 数据X, 聚类数k
输出: 聚类标签

1. 随机初始化k个中心 μ₁, μ₂, ..., μₖ
2. repeat:
   3. 分配: 将每个点分配到最近的中心
      c^(i) = argmin_j ||x^(i) - μ_j||²
   4. 更新: 重新计算中心
      μ_j = mean({x^(i): c^(i) = j})
5. until 中心不再变化
```

### 2. 目标函数
J = Σⱼ Σᵢ∈Cⱼ ||x^(i) - μ_j||²

### 3. 确定k值
- 肘部法则: 看拐点
- 轮廓系数: 越大越好

## 五、神经网络反向传播

### 1. 前向传播
z^(l) = W^(l)a^(l-1) + b^(l)
a^(l) = σ(z^(l))

### 2. 损失函数
L = ½Σ(y - ŷ)²

### 3. 反向传播
δ^(L) = ∂L/∂z^(L) = (a^(L) - y) · σ'(z^(L))
δ^(l) = ((W^(l+1))ᵀδ^(l+1)) · σ'(z^(l))

### 4. 梯度计算
∂L/∂W^(l) = δ^(l)(a^(l-1))ᵀ
∂L/∂b^(l) = δ^(l)

### 5. 参数更新
W^(l) = W^(l) - η · ∂L/∂W^(l)
b^(l) = b^(l) - η · ∂L/∂b^(l)
