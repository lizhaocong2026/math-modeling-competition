# 智能优化算法理论

## 一、遗传算法 (GA)

### 1. 生物学基础
- **选择**: 适者生存
- **交叉**: 基因重组产生新个体
- **变异**: 基因突变增加多样性

### 2. 算法流程
```
1. 初始化种群 P(t)
2. 评估适应度 f(x)
3. while 终止条件不满足:
   4. 选择操作 → 交配池
   5. 交叉操作 → 新种群
   6. 变异操作 → 新种群
   7. t = t + 1
8. 输出最优解
```

### 3. 关键参数
| 参数 | 典型值 | 影响 |
|------|--------|------|
| 种群大小 | 50-200 | 大→精度高，慢 |
| 迭代次数 | 100-500 | 大→收敛充分 |
| 交叉概率 | 0.6-0.9 | 大→搜索力强 |
| 变异概率 | 0.001-0.1 | 大→多样性好 |

### 4. 编码方式
- **二进制编码**: 经典方法
- **实数编码**: 连续优化
- **排列编码**: TSP等组合问题

## 二、粒子群优化 (PSO)

### 1. 基本原理
模拟鸟群捕食行为，每个粒子代表一个候选解。

### 2. 速度-位置更新
```
v_id = ωv_id + c₁r₁(pbest_id - x_id) + c₂r₂(gbest_d - x_id)
x_id = x_id + v_id
```

### 3. 参数说明
- ω: 惯性权重 (0.4-1.2)
- c₁, c₂: 学习因子 (通常=2)
- pbest: 个体最优
- gbest: 全局最优

### 4. 变种
- **标准PSO**
- **带惯性权重PSO**
- **收缩因子PSO**
- **邻域PSO**

## 三、模拟退火 (SA)

### 1. 物理背景
固体退火过程：加热→缓慢冷却→晶体最稳定

### 2. Metropolis准则
```
若 E_new < E_old: 接受
若 E_new ≥ E_old: 以概率 exp(-ΔE/T) 接受
```

### 3. 算法流程
```
1. 初始化: 选初解x, 高温T
2. while T > T_min:
   3. 生成新解x'
   4. 计算ΔE
   5. 按Metropolis准则决定是否接受
   6. T = T × α (冷却)
7. 输出最优解
```

### 4. 参数选择
- 初始温度: 使接受概率≈0.8
- 冷却系数α: 0.95-0.999
- 终止温度: 足够小

## 四、差分进化 (DE)

### 1. 算法流程
```
for each个体i:
   1. 随机选a,b,c ≠ i
   2. 变异: v = x_a + F(x_b - x_c)
   3. 交叉: u_j = v_j (rand < CR) or x_ij
   4. 选择: x_i = u (若f(u)<f(x))
```

### 2. 参数
- F: 缩放因子 (0.5-1)
- CR: 交叉概率 (0.1-1)
- NP: 种群大小 (10×维度)

## 五、蚁群算法 (ACO)

### 1. 信息素更新
```
τ_ij ← (1-ρ)τ_ij + ΣΔτ_ij
Δτ_ij^k = Q/L_k (若蚂蚁k经过ij)
```

### 2. 转移概率
```
p_ij^k = [τ_ij^α][η_ij^β] / Σ[τ_il^α][η_il^β]
```

### 3. 参数
- α: 信息素重要性
- β: 启发式因子重要性
- ρ: 信息素挥发系数

## 六、算法选择指南

| 问题类型 | 推荐算法 | 原因 |
|----------|----------|------|
| 连续优化 | DE, PSO | 收敛快 |
| 离散优化 | GA, ACO | 编码灵活 |
| 多峰函数 | SA, GA | 跳出局部最优 |
| 组合优化 | ACO, GA | 结构匹配 |
| 高维问题 | DE, PSO | 效率高 |
