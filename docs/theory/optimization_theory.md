# 数学建模理论基础

## 一、优化理论

### 1. 线性规划 (Linear Programming)

#### 数学模型
```
minimize    c^T x
subject to  Ax ≤ b
            x ≥ 0
```

#### 核心概念
- **可行域**: 满足所有约束的解空间
- **最优解**: 使目标函数达到极值的可行解
- **对偶理论**: 每个LP问题都有对应的对偶问题

#### 求解方法
| 方法 | 适用场景 | 复杂度 |
|------|----------|--------|
| 单纯形法 | 小规模问题 | O(n³) |
| 内点法 | 大规模问题 | O(n^3.5) |
| 高斯消元 | 等式约束 | O(n³) |

#### 重要定理
- **强对偶定理**: 若原问题有最优解，则对偶问题也有最优解，且目标值相等
- **互补松弛性**: x_j * (A^T λ - c)_j = 0

---

### 2. 整数规划 (Integer Programming)

#### 分类
- **纯整数规划**: 所有变量为整数
- **混合整数规划**: 部分变量为整数
- **0-1规划**: 变量取0或1

#### 经典问题
1. **指派问题**: n人n任务，每人做一个任务
2. **旅行商问题(TSP)**: 访问所有城市一次且仅一次
3. **背包问题**: 在容量限制下最大化价值

#### 求解算法
- 分支定界法
- 割平面法
- 隐枚举法

---

### 3. 非线性规划 (Nonlinear Programming)

#### 标准形式
```
minimize    f(x)
subject to  g_i(x) ≤ 0, i = 1,...,m
            h_j(x) = 0, j = 1,...,p
```

#### KKT条件 (必要性)
若x*是局部最优解，且约束规范成立，则存在λ, μ使得:
```
∇f(x*) + Σλ_i∇g_i(x*) + Σμ_j∇h_j(x*) = 0
λ_i ≥ 0, λ_i * g_i(x*) = 0
g_i(x*) ≤ 0, h_j(x*) = 0
```

#### 常用算法
- 梯度下降法
- Newton法
- 序列二次规划(SQP)
- 信赖域法

---

### 4. 动态规划 (Dynamic Programming)

#### 基本原理
- **最优子结构**: 最优解包含子问题的最优解
- **重叠子问题**: 子问题被重复计算

#### Bellman方程
```
V(s) = max_a [R(s,a) + γΣ_s' P(s'|s,a)V(s')]
```

#### 适用场景
- 资源分配
- 路径规划
- 生产库存问题
