# 预测模型理论

## 一、时间序列分析

### 1. 平稳性检验

#### 定义
时间序列{x_t}是平稳的，若:
- E[x_t] = μ (常数)
- Cov(x_t, x_{t+k}) = γ_k (只与k有关)

#### 检验方法
| 方法 | 原理 | 适用 |
|------|------|------|
| ADF检验 | 单位根检验 | 最常用 |
| KPSS检验 | 平稳性检验 | 互补使用 |
| 自相关图 | 视觉判断 | 初步分析 |

---

### 2. ARIMA模型

#### 基本形式
```
φ(B)(1-B)^d x_t = θ(B)ε_t
```

其中:
- B: 后移算子, Bx_t = x_{t-1}
- φ(B): AR部分
- θ(B): MA部分
- d: 差分阶数

#### 参数识别
1. **p的确定**: 看ACF截尾，PACF拖尾
2. **d的确定**: 看ADF检验，使序列平稳
3. **q的确定**: 看PACF截尾，ACF拖尾

#### 定阶准则
- AIC = 2k - ln(L)
- BIC = kln(n) - ln(L)
- 选择使准则最小的(p,q)

---

### 3. 灰色预测 GM(1,1)

#### 建模步骤
1. **数据检验**: 级比λ(k) = x(k-1)/x(k) ∈ (e^{-2/(n+1)}, e^{2/(n+1)})
2. **累加生成**: x^(1)(k) = Σx^(0)(i)
3. **建立微分方程**: dx^(1)/dt + ax^(1) = b
4. **参数估计**: â = (a,b)^T = (B^TB)^{-1}B^TY
5. **求解拟合**: x^(1)(k) = (x^(0)(1)-b/a)e^{-ak} + b/a
6. **累减还原**: x^(0)(k) = x^(1)(k) - x^(1)(k-1)

#### 精度检验
| 等级 | C值 | P值 |
|------|-----|-----|
| 好 | <0.35 | >0.95 |
| 合格 | <0.50 | >0.80 |
| 勉强 | <0.65 | >0.70 |
| 不合格 | ≥0.65 | ≤0.70 |

## 二、回归分析

### 1. 线性回归

#### 模型
```
y = β_0 + β_1x_1 + ... + β_px_p + ε
```

#### 最小二乘估计
```
β̂ = (X^TX)^{-1}X^Ty
```

#### 统计检验
- **t检验**: H₀: βⱼ = 0
- **F检验**: H₀: β₁ = β₂ = ... = βₚ = 0
- **R²**: 决定系数，解释方差比例

---

### 2. 多项式回归

#### 模型
```
y = β_0 + β_1x + β_2x² + ... + β_d x^d + ε
```

#### 过拟合问题
- **正则化**: Lasso (L1), Ridge (L2), Elastic Net
- **交叉验证**: 选择最优阶数d

---

### 3. 逻辑回归 (分类)

#### 模型
```
P(y=1|x) = 1/(1 + e^{-(β_0 + β^Tx)})
```

#### 损失函数
```
L(β) = -Σ[y_i ln(p_i) + (1-y_i)ln(1-p_i)]
```
