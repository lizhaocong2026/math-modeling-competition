## 六、典型赛题应用

| 赛题类型 | 推荐数据源 | 推荐算法 |
|----------|-----------|---------|
| 土地利用变化预测 | GLCF + 遥感数据共享 | 马尔可夫 + Cellular Automata |
| 空气质量预测 | PM25.in + 中国气象科学数据 | ARIMA / LSTM |
| 水土保持评估 | 黄土高原水土保护数据库 | AHP + TOPSIS |
| 森林资源评估 | FAO GFMD + FRA 2000 | 统计描述 + 回归 |
| 城市热岛效应 | MODIS + NASA Reverb | 空间插值 + 回归 |
| 水资源评价 | 黄河流域数据中心 + NCDC | 熵权法 + VIKOR |
