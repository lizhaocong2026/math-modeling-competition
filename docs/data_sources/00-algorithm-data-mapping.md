## 四、数据源 → 适用算法映射

### 金融财经数据（16个来源）
→ 适用算法：ARIMA, LSTM, 均值-方差, NSGA-II, 蒙特卡洛, 贝叶斯推断
→ 典型赛题：投资组合优化、汇率预测、风险评估

### 互联网/报告数据（20个来源）
→ 适用算法：Prophet, ARIMA, 聚类, 分类, 集成学习
→ 典型赛题：APP活跃度分析、电商销量预测、社交媒体热度预测

### 地理环境遥感数据（49个来源）
→ 适用算法：PCA, Cellular Automata, 空间插值, 马尔可夫, 核密度估计
→ 典型赛题：土地利用变化预测、空气质量预测、水土评估

### 政府/行业数据（24个来源）
→ 适用算法：AHP, TOPSIS, 熵权法, ARIMA, GM(1,1), 线性规划
→ 典型赛题：人口预测、城市评价、区域经济分析
