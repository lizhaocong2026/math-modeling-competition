## 🎯 学习路径

### 第一阶段：基础准备（2周）
1. 学习Python基础
2. 掌握NumPy、Pandas
3. 学习Matplotlib绘图

### 第二阶段：核心算法（3周）
1. 优化算法：线性规划、遗传算法
2. 预测模型：GM(1,1)、回归分析
3. 评价方法：AHP、TOPSIS

### 第三阶段：进阶提升（2周）
1. 时间序列分析
2. 图像处理基础
3. 集成学习方法

### 第四阶段：实战演练（1周）
1. 刷历年真题
2. 模拟竞赛
3. 论文写作训练

## 🔧 环境安装

```bash

pip install statsmodels seaborn

pip install torch tensorflow
```
